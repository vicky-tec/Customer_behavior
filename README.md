# 📊 Customer Behavior Data Analytics Project  

A complete **end-to-end data analytics project** that demonstrates how to transform raw data into meaningful business insights using **Python, SQL, and Power BI**.  
This project simulates a real-world analytics workflow — from data loading and cleaning to dashboard building and final reporting.

---

## 🧩 Overview  

The goal of this project is to analyze customer behavior data to uncover key trends and actionable insights for business decision-making.  
The workflow includes:  

- Loading and cleaning raw data in **Python**  
- Performing **Exploratory Data Analysis (EDA)** to understand patterns  
- Running **SQL queries** to answer business questions  
- Creating an interactive **Power BI dashboard** for visualization  
- Preparing a **final report and presentation** using **Gamma AI**

---

## 📁 Dataset  

The dataset contains transactional-level customer shopping information, including:  

| Column | Description |
|---------|-------------|
| CustomerID | Unique identifier for each customer |
| Gender | Male/Female |
| Age | Age of the customer |
| Category | Product category purchased |
| Product_ID | Unique product code |
| Price | Product price per unit |
| Quantity | Number of units purchased |
| Purchase_Amount | Total purchase value |
| Date | Date of transaction |
| Payment_Method | Mode of payment |
| City | City of the customer |

🗂️ *File:* `customer_shopping_data.csv`

## ⚙️ Steps / Workflow  

### 1️⃣ Data Loading (Python)  
- Import dataset using **Pandas**  
- Check for missing values and data types  

### 2️⃣ Exploratory Data Analysis (EDA)  
- Analyze sales by category, gender, and region  
- Visualize distributions and correlations using **Matplotlib** and **Seaborn**  

### 3️⃣ Data Cleaning  
- Handle null values and duplicates  
- Format dates and standardize column names  

### 4️⃣ SQL Analysis  
- Load cleaned data into SQL database  
- Write queries to answer key business questions such as:  
  - Top 5 cities by total purchase value  
  - Most popular product categories  
  - Average spend by customer segment  
  - Month-wise revenue trend  

### 5️⃣ Power BI Dashboard  
- Connect SQL database to Power BI  
- Build an interactive dashboard showing:  
  - 🏙️ Top-performing cities  
  - 💳 Payment method breakdown  
  - 📈 Monthly sales trends  
  - 🧍 Gender-wise spending patterns  

### 6️⃣ Report & Presentation  
- Prepare a concise **project report** summarizing insights and KPIs  
- Design a **presentation deck using Gamma AI** highlighting business outcomes

## 📈 Results & Insights  

Key takeaways from the analysis:  
- 🛍️ Majority of purchases come from the **Clothing** and **Electronics** categories  
- 👩 Female customers tend to have a **higher average purchase amount**  
- 💳 **UPI and Credit Cards** are the most frequently used payment methods  
- 🏙️ Top cities contributing to sales are **Delhi, Mumbai, and Bangalore**  
- 📅 Seasonal spikes in sales observed during **festive months**
